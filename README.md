# BLAY v1.8

BLAY Android client + online backend prototype.

## v1.8
- Android client project
- Owner/Client foundation
- Android Keystore RSA device identity
- Foreground standby service foundation
- SpeechRecognizer + Indonesian TTS
- Server URL configuration
- GitHub Actions APK build workflow
- FastAPI online server prototype
- AI Router interface for Qwen2.5 7B, SahabatAI 8B, and Phi-3.5 Mini

This is a prototype. The custom "Blay" wake-word model and production model hosting are not included.
